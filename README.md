# Kondensator-Labor VR

Virtuelles Physiklabor fürs Handy: Die Kapazität eines Plattenkondensators wird experimentell bestimmt. Gemessen werden Q(U), C(d), C(A) und C(εᵣ), mit Diagramm und Ausgleichsgerade.

**Starten:** https://felixpasold-dev.github.io/kondensator-labor-vr/

- Wischen zum Umsehen, Tippen zum Bedienen
- **Cardboard:** geteiltes Bild mit Kopfsteuerung. Ziel anvisieren und kurz warten oder antippen. Funktioniert auch auf dem iPhone.
- **VR-Brille:** erscheint, wenn das Gerät WebXR unterstützt (z. B. Chrome auf Android, Meta Quest)
